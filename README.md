# Interview
New joiner

## แบบสอบถามพนักงานใหม่ (1–90 วัน) — แผนกคลังสินค้า โรงงานไก่แปรรูป

- `index.html` — แบบฟอร์มออนไลน์ไฟล์เดียว ใช้งานบนมือถือได้ รองรับ 4 ภาษา: ไทย · ລາວ · ខ្មែរ · မြန်မာ
- `QUESTIONS.md` — รายการคำถาม มิติที่วัด และวิธีคำนวณคะแนนความเสี่ยงลาออก
- `apps-script.gs` — สคริปต์เก็บคำตอบลง Google Sheet

### การใช้งาน
1. เปิดใช้งานผ่าน GitHub Pages (Settings > Pages > Branch) หรือโฮสต์ไฟล์ `index.html` ที่ใดก็ได้ แล้วทำ QR Code แจกพนักงาน
2. ถ้าต้องการเก็บคำตอบรวมศูนย์ ให้ติดตั้ง `apps-script.gs` แล้วใส่ URL ในตัวแปร `SUBMIT_URL` ใน `index.html`
   (ถ้าไม่ใส่ พนักงานจะดาวน์โหลดไฟล์คำตอบ .json ส่งให้ฝ่ายบุคคลแทน)
3. คำตอบแบบตัวเลือกบันทึกเป็นภาษาไทยเสมอ ไม่ว่าพนักงานจะตอบเป็นภาษาใด เพื่อให้วิเคราะห์รวมกันได้

> คำแปลภาษาลาว เขมร และพม่า ควรให้ล่าม/พนักงานเจ้าของภาษาตรวจทานก่อนใช้งานจริง
